# 模型与算法迭代记录

按时间顺序记四次实质改动，每次只写「改了什么、为什么改、结果如何」。

## v1 · 基线：MobileNetV3-Small，无归一化

- 训练：L1/L2 共 130 张，224×224，25 epoch，AdamW
- 评估：跨光照，用没见过的 L3/L4 测试
- **结果：整体 94.6%（L3 90.8%、L4 98.5%）**
- 看混淆矩阵，6 个错误全是 **O4 透明玻璃瓶 → O5 亮面包装盒**
- 产物：`results/model_crosslighting_none.pt`、`metrics_crosslighting_none.json`

## v2 · 加 CLAHE 局部对比度归一化

- 改动：LAB 空间对亮度通道做 CLAHE（clipLimit=2，8×8 网格），**训练和推理都加**
- 动机：v1 的错误集中在透明件，判断是局部对比度丢失（强光下边缘消失）
- **结果：L3、L4 全部答对，整体 100%**
- 产物：`results/model_crosslighting_clahe.pt`

## v3 · 部署模型 + 拒识

- 改动一：用全部 260 张训练部署模型（不再留出验证集）
- 改动二：推理端加拒识，置信度 < 0.6 输出「未知」而不是硬判
- **结果：分布内置信度 0.99+，常规物件拒识率 0.20%**
- 产物：`results/model_all_clahe.pt`、`src/runner.py`

## v4 · 补光对照实验（不用于部署）

- 改动：新增 L5 数据集 65 张——主光（L3 强反光）完全不动，只在对侧 45° 加一盏蒙纸巾的补光
- **结果：无归一化下 90.8% → 96.9%**
  - O4 透明玻璃瓶召回 0.50 → **1.00**（补光直接解决）
  - O3 金属钥匙 1.00 → **0.83**（补光在金属上形成第二处高光）
  - 加 CLAHE 后两种光照都是 100%
- 产物：`data/L5_补光/`、`src/eval_fill.py`、`results/fill_light.png`

## 没有做的部分

- **多物件同框与计数**：目前只覆盖单件摆放
- **时序平滑**：连续 N 帧一致才输出，可以进一步压掉边界抖动
- **拆分补光的方向性贡献**：缺一组「只把主光调亮」的对照
