# 项目二 · 多光照数据集拍摄器

一个本地小程序（不是网页）。左边是摄像头实时画面，右上角显示**现在该拍什么**，
按空格或点右侧按钮就拍一张，照片自动存进按「光照 / 物件」分好的文件夹。

## 怎么用

1. 双击 **`自检.bat`** —— 确认能开摄像头、能存图、EXIF 正常（会存 3 张到 `_selftest/`）
2. 双击 **`运行.bat`** —— 打开拍摄界面
3. 按提示拍：每组拍满会自动跳到下一个物件 / 下一个光照

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` / 回车 / 按钮 | 拍一张 |
| `Backspace` | 撤回上一张（连文件一起删） |
| `1` `2` `3` `4` | 直接切到 L1–L4 |
| `A` `B` `C` `D` `E` | 直接切到第 1–5 件物件 |
| `Z` | 切到「空桌面」 |
| `S` | 跳过本组 |
| `Esc` | 退出 |

## 拍摄顺序（自动）

```
L1 均匀顶光 → O1..O5 各 12 张 → 空桌面 5 张
L2 弱光     → O1..O5 各 12 张 → 空桌面 5 张
L3 强反光   → O1..O5 各 12 张 → 空桌面 5 张
L4 阴影     → O1..O5 各 12 张 → 空桌面 5 张
```

合计 **260 张**（物件 240 + 空桌面 20）。要求是「不少于 200」，留了 20% 余量给废片。

## 文件夹

```
data/
  L1_均匀顶光/
    O1_白瓷杯/     L1_O1_01_20261115_201322.jpg ...
    O2_深色充电宝/
    ...
    空桌面/
  L2_弱光/ ...
```

**目录名就是标签**，训练脚本按目录读，不用另做标注。

## 改物件名字

改 `config.json` 里的 `objects`：

```json
"objects": [
  {"code": "O1", "name": "白瓷杯"},
  {"code": "O2", "name": "深色充电宝"},
  {"code": "O3", "name": "金属钥匙"},
  {"code": "O4", "name": "玻璃杯"},
  {"code": "O5", "name": "亮面包装盒"}
]
```

**开工前改好**，拍了一半再改会导致新旧文件分到两个文件夹。

## 每张照片里都有什么

- EXIF `DateTimeOriginal` / `DateTime`：拍摄时间（真机时间）
- EXIF `Make` / `Model`：`UVC Camera` / `USB Camera`
- 文件名带序号和毫秒级时间戳，同组内可排序

另外 `session_log.csv` 会追加每一张的记录（时间、光照、物件、序号、路径），
可以直接当 `process_logs/` 的过程数据。

## 拍摄要点

- 机位钉死：支架位置、台面中心贴胶带，四个光照之间不许挪
- 关掉摄像头的自动曝光/自动增益（如果有配套软件）；本程序不干预画面，画面原样存
- L3 要拍到明显高光斑，L4 要拍到明显半明半暗，否则模型不会变差，报告就没故事
- 拍完先看一张：画面里只有台面和物件，没有杂物、证件、快递单

## 出问题怎么办

- **摄像头未就绪**：拔插 USB，或改 `config.json` 的 `camera_index`（0/1/2 试一下）
- **画面卡**：关掉其他占用摄像头的软件（相机、会议软件）
- **拍到一半关了**：重开程序会自动从没拍满的那组继续
