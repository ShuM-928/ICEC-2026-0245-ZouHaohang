# 第二阶段：项目二（进行中）

## 选题

**低成本桌面级智能视觉状态检测与抗光照干扰实证装置**

- 场景：桌面 5 类日常物品的识别与在位判断（分类 + 拒识）
- 目标：解决强弱光、台灯反光、阴影遮挡导致的误检
- 关键设计：4 光照 × 5 物件 × 10 张 = 200 张数据集，另拍 20 张空场景标定拒识阈值

## 目录

```
src/                采集、训练、检测、日志、评估脚本
data/               数据集（按 光照/物件 分目录，目录即标签）
process_logs/       按日期归档的过程记录（每天一份 notes.md + 截图）
iterations/         模型与算法迭代记录（v1 → v2 → v3，含 diff 说明）
```

## process_logs 规则

- 每次开工建一个 `YYYY-MM-DD/` 目录
- 记录：当天做了什么、参数、遇到的问题、下一步
- 当天提交，不补录
