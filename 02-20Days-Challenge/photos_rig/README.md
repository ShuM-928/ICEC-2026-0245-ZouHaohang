# 实物演进照（3 张）

题目要求 `02-20Days-Challenge/` 里包含「实物演进照」。这三张记录了装置与光照条件的变化过程：

| 文件 | 说明 |
|---|---|
| 01_五件样本同框.jpg | 五件日常样本（白色按压瓶、深色充电宝、金属钥匙、透明玻璃瓶、亮面包装盒）同时摆在拍摄台上的样子，用于确认五类之间的可区分性 |
| 02_强反光布置.jpg | L3 条件：台灯直射物件，透明玻璃瓶在强光下边缘几乎消失——这是模型最容易失效的工况 |
| 03_补光布置.jpg | L5 条件：主光不动，在对侧 45° 加一盏蒙纸巾的补光，同一只玻璃瓶的边缘重新可辨 |

拍摄装置：USB 摄像头（icspring，1920×1080）固定在三脚架上，45° 俯视台面，台面贴十字胶带定位；手动关闭自动曝光与低照度补偿，保证四种光照真正进入数据。
