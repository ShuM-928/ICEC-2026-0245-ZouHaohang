# 多光照数据集（完整 325 张）

完整数据集 **325 张**（260 张四光照 + 65 张补光），全部在本仓库内。

## 为什么一开始只放了 60 张样例

按提交说明第 ② 条，**200 张以上的原图包不建议塞进 GitHub**——会占仓库体积、拖慢 clone，评审下载也不方便。

所以第一版每种光照 × 每个类别只保留 2 张，共 60 张，留来证明三件事：

1. **目录结构看得懂**——`L1_均匀顶光/O4_透明玻璃瓶/` 这种命名，一眼能看出标签是怎么来的
2. **图像质量可判**——每类有两张，能看出这类的典型样子和不同光照下的差异
3. **clone 不心疼**——60 张约 9 MB

完整数据当时走校内门户的「大文件分片上传」。

## 为什么后来改成全量

因为**评审主要还是看仓库**。

数据是这份作品最核心的证据，不该让评审为了核对一张图去另一个系统里翻。325 张约 50 MB，GitHub 允许，clone 也就多等十几秒。

所以现在是下面这样，门户那份保留作备份：

| | 第一版（样例） | 现在（全量） |
|---|---|---|
| 仓库体积 | 约 9 MB | 约 50 MB |
| 评审体验 | 要看全量得另开系统 | 点开就能看 |
| 数据完整性 | 靠门户补 | 一处齐全 |

对这份作品来说，**评审体验比 clone 速度重要**。

## 目录约定

```
data/
  L1_均匀顶光/  O1_白色按压瓶/  O2_深色充电宝/  O3_金属钥匙/
                O4_透明玻璃瓶/  O5_亮面包装盒/  空桌面/
  L2_弱光/      ……同上
  L3_强反光/    ……同上
  L4_阴影遮挡/  ……同上
  L5_补光/      ……同上（仅用于补光对照实验）
```

| 光照 | 含义 |
|---|---|
| L1 | 均匀顶光（开顶灯，关台灯） |
| L2 | 弱光（灯打墙反射，不直射台面） |
| L3 | 强反光（灯直射物件，能看到高光斑） |
| L4 | 阴影遮挡（侧光 + 挡板，一半落进阴影） |
| L5 | 补光（L3 基础上，对侧 45° 加一盏蒙纸巾的灯） |

**目录名就是标签**，训练脚本按目录读取，不需要额外标注文件。每格 12 张，空桌面 5 张。

## 每张图的证据

- JPEG 内含 EXIF `DateTimeOriginal`（例：2026:11:15 20:54:58）
- 文件名带序号与到秒的时间戳：`L1_O1_01_20261115_205458.jpg`
- 拍摄时的完整记录见 `../process_logs/2026-11-15/`（260 张的逐张 CSV）与 `src/camera_shoot.py`

## 补光那 65 张

L5 是在 L3 强反光的基础上、**主光完全不动**、只在对侧 45° 加一盏蒙纸巾的补光拍成的。
用只见过 L1/L2 的模型测，透明玻璃瓶召回率从 0.50 升到 1.00，整体从 90.8% 升到 96.9%。
详见 `report/02_项目二_报告.pdf` 第八节。
