## 数据说明

**06 声学**：17 段 44.1 kHz / 16 bit 单声道原始录音，每段 49–101 秒；声级由录音计算（Leq，A 计权近似），
以手机分贝计读数为锚点标定（未计权偏移 88.5 dB，四点偏差 ≤ 0.8 dB）。CSV 中同时给出 L1 / L10 / L90。

**03 无线**：WiFi Analyzer 读取 BSSID / RSSI / 信道 / 链路速率，网络测速 App 记录上下行，
PING 工具测到网关 `10.100.44.254` 的延迟。覆盖扫描 20 组（8 个位置），受控实验两组（单 AP 多距离）。
